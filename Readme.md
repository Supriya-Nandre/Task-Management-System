# Task Management System

## Project Description
Task Management System is a simple web application developed using HTML, CSS, and JavaScript. The project allows users to add tasks, mark tasks as completed, delete tasks, and filter tasks based on their status. This project demonstrates practical implementation of GitHub collaboration workflows including repository management, branching, merging, pull requests, and GitHub Actions.

---

## Features
- Add New Tasks
- Mark Tasks as Completed
- Delete Tasks
- Filter Tasks (All / Completed / Pending)
- Simple and User-Friendly Interface
- GitHub Collaboration Workflow
- GitHub Actions Integration
